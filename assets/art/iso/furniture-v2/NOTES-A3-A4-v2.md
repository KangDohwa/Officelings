# FURNITURE v2 — A3/A4 handoff

Made six families in SE/SW/NE/NW: compact wood desk with chunky cream CRT, keyboard, drawer pedestal, mug/note; plush teal chair with disjoint rear/front layers; red three-seat sofa with loose pillows; patterned blue rug; wood TV cabinet with play screen and cubby; small wood side table with mug/note. Eleven `.iso.json` manifests and fifty PNGs include empty reconstructions, screen masks, shadows and five review boards. `furniture-review.png` and `furniture-fixture-room.png` are exact 3×; `v1-vs-v2.png` includes native insets and 3× views beside width-normalized hero crops. The room uses S0 placements and placeholder seated rigs.

**No frozen spec/contact change.** V1 part IDs, source anchors/cells, footprints, seat profiles, pelvis/hand contacts, depth keys and seat ranks were preserved and compared against the existing manifests. The existing [part convention](../furniture/furniture-part-convention.md) still applies; it was not rebuilt. Sofa SE remains 1×3, with SW/NE 3×1. Desk default resolves off; working is four distinct 3fps phases; screensaver is static. TV has four 3fps glass/LED phases with unchanged play-icon pixels. Static-body bytes remain identical across states.

Method: sprite-gen Codex still pipeline, six front masters plus three genuinely hidden rear masters (desk/chair/sofa), one generation attempt each. Derive other views through component reprojection/recomposition and baked anchor-preserving mirrors, with upper-left shade repair. Mug handles are moved as components instead of flipped. Chroma cleanup, nearest-neighbor native conversion, exact frozen-palette snap, binary alpha and geometric edge repair follow generation. Actual generated pixels enter production; the concept is a visual reference. Raw masters, prompts, guides, reports, native masters, builder and verification remain in `runs/furniture-v2/`. No flat/v1 art, pack, shared code or docs were changed; no commit.

Estimated lane time: **about 0.63 lane-hours (~38 minutes)**, including reading/preparation, generation waits, pixel repairs and validation. Run timestamps cover approximately 05:10–05:38 KST; preceding reading/preparation is estimated at ten minutes, not measured. Nine provider reports total **523.4 seconds**; that is generation time, not the entire lane time. Generations ran one at a time. Fourteen image views were used, including required concept/fixture references and composites.

Validation: `python tools/iso_check.py assets/art/iso/furniture-v2 --tolerance 0 --check-reference`: **105 checks, 0 failed**, output kept in `runs/furniture-v2/iso-check-final.txt`. Independent serialized-export verification has **44 PASS records** in `export-validation.txt`: disjoint reconstruction, linked assets/shadows, S0 desk C/H table at **0px error**, chair pelvis ink, screen-mask confinement/body equality, distinct screen frames, fixed TV icon, byte-identical rug opposite pairs, unchanged v1 names/anchors/variant contracts. Floor seams and character face-lock remain explicit checker skips. The last prop-coordinate/planar-mask cleanup was verified programmatically after the image-view budget was used.

Remaining weaknesses: NW desk grain is busier and its recomposed props are less elegant than the direct SE/NE masters. Rear chair remains squat beside the front view; the rug pattern is stronger than the hero. Mirrored upholstery shading is less natural than the directly generated faces. Some preserved edge-part masks are thin after the compact silhouette; final-character silhouettes and passing walkers still need the integrator's WPF/occlusion review. This lane did not establish runtime acceptance.

Spec assumptions: no S0 change requested. A future spec could separate blocking footprint from an explicit visual desk surface extent, which would make personal-desk proportions easier to freeze. The existing 128px sofa shadow cell still limits a full-footprint (+6,+3) cast; v2 retains the inset solution. Packaging should standardize the existing private `linkedChair`/`shadow` hooks.
