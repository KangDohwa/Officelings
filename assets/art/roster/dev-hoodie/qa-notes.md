# dev-hoodie 검수 기록

codex 정지 이미지 행 생성 → 크로마 제거 → pixel_unfake/32색 팔레트 → canonical atlas/export 경로를 사용했습니다. 기본 이미지, 생성된 모든 raw 행(폐기된 행 포함), 모든 최종 프레임을 직접 보았습니다. 아래는 프레임을 나란히 본 정적 판정입니다. GIF 파일은 생성했으나 연결된 브라우저가 없어 재생을 보지 못했습니다. 루프 연결과 실제 보행 리듬을 통과한 것으로 간주하지 않습니다.

왼쪽 보행의 네 번째 프레임 크기 변화를 발견해 행 전체를 재생성했습니다. 이후 네 프레임에 같은 1.18배 NEAREST 변환과 발 정렬을 적용해 오른쪽 보행과 크기를 맞췄습니다. 변경은 run/curation.json에 기록되어 있습니다.

| 상태 | 정적 검수와 한계 | 모션 판정 |
|---|---|---|
| idle | 네 방향, 의상과 머리 특징 유지. 정지 방향 슬롯입니다. | 해당 없음 |
| walk_down | 발·팔 포즈 변화와 아래 방향을 확인했습니다. | experimental; 재생 미검증 |
| walk_left | 좌향 포즈와 발 교대를 확인했습니다. | experimental; 재생 미검증 |
| walk_right | 우향 포즈와 발 교대를 확인했습니다. | experimental; 재생 미검증 |
| walk_up | 뒤통수·의상과 발 교대를 확인했습니다. | experimental; 재생 미검증 |
| typing_back | 뒤쪽 작업 포즈, 가구 없음. 손과 어깨 변화는 작습니다. | 재생 미검증 |
| typing_side | 옆 작업 포즈, 가구 없음. 손가락 디테일은 미세합니다. | 재생 미검증 |
| report | 종이를 꺼내고 앞으로 내미는 단계가 읽힙니다. idle보다 작은 행 단위 크기는 남습니다. | 시작·중간·끝 정적 검수; 재생 미검증 |
| sleep | 눈을 감고 몸을 낮춘 두 포즈, 가구 없음. | 재생 미검증 |
| coffee | 컵을 들고 입에 올렸다가 내리는 단계, 컵과 손 접촉 확인. | 재생 미검증 |
| phone | 손에 붙은 작은 휴대폰 확인. 입력 동작 차이는 작습니다. | 재생 미검증 |
| talk | 손 제스처 차이와 의상 유지 확인. | 재생 미검증 |
| surprised | 눈을 크게 뜨고 두 손을 올리는 차이 확인. !는 별도 런타임 표시. | 시작·끝 정적 검수; 재생 미검증 |

남은 시각적 약점: report 행은 서 있는 idle보다 인물이 작습니다. typing_side와 phone의 손가락 변화는 미세하며, 짙은 피부와 헤드폰은 원래 32px 폭에서 일부 세부가 합쳐집니다.

최종 구조 검사: worker의 셀·행 순서·프레임 수·FPS·반복값과 비교, 42개 유효 셀/빈 열, 이진 알파, 최종 시트와 개별 PNG의 픽셀 일치를 확인합니다. 추출기의 pitch/physical-cap 경고가 있는 행은 시각 검수로 확인했으며 경고가 모두 사라졌다고 보고하지 않습니다. canonical 보정이 있는 경우 최종 검수 대상은 run/sheet-review.png 및 run/curated/이며 run/qa의 원본 추출 미리보기와 다를 수 있습니다.
